# pyidfm - Ile de france mobilités API

AI-ready Python API wrapper for the Ile de France mobilités open-data API, allowing to
retrieve next schedules for stations on specific lines and traffic information
for lines. Supports Metro, RER, Transilien, Tram, and BUS.

Designed as generic skills to be invoked by an LLM agent, with a focus on fetching next
suburban train departures (RER and Transilien) for stations in the Paris / Île-de-France
area.

Implementation is an heavily modified version of the original [`idfm-api`](https://pypi.org/project/idfm-api/)
package, with a focus on reliability and LLM-friendliness rather than raw feature completeness.


## Installation

1. Install the package and its dependencies:

   ```sh
   pip install pyidfm
   ```
